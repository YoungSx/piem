## 2025-02-26 - [Chat Composer Chevron Fix]
**Learning:** Found a reversed UI convention for chevron toggle icons. In a bottom-anchored panel like a chat composer, the 'expand' action makes it grow upwards, so the toggle icon should point UP when collapsed. Conversely, to collapse it back to the bottom, the icon should point DOWN when expanded.
**Action:** Always consider the visual anchor and direction of growth when selecting directional icons like chevrons for expand/collapse actions.
