# 扩展 Piem

[← 回到 README](../README.zh-CN.md) · [English](extending.md)

给 Piem 加东西有两条路：**技能**，是它能遵循的指令；**MCP 服务器**，是它能调
用的工具。

## 技能

技能是一段可复用的指令，代理能遵循它，你也能在输入框敲 `/` 直接调它。Piem 从
三处折叠技能，后面的层级覆盖前面的：

1. **内置** —— `summarize`、`link-graph`、`tag-organize`、`find-skills`。已本
   地化，在你创建任何文件之前就能用。它们在仓库里根本没有文件；`read_skill`
   从内存里返回内容。
2. **仓库** —— 你仓库里的 `Piem/skills/<名字>/SKILL.md`。这个目录在 Obsidian
   的文件浏览器里看得见，所以你可以像对待任何笔记一样打开、搜索、链接、同步
   自己的技能。
3. **用户级** —— `~/.pi/agent/skills` 和 `~/.agents/skills`，也就是 pi 自己
   读的那两个目录。你早先为 pi 写的技能，在这里原样可用。

### 写一个

一份 `SKILL.md` 需要两个 frontmatter 字段：

```markdown
---
name: weekly-review
description: 收集本周的日记笔记，据此起草一份周复盘。
---

读最近七天的每篇日记笔记。把标了 #decision 或 #blocked 的内容挑出来。用
Templates/Weekly.md 的模板，在 Reviews/ 下起草一份复盘。
```

- `name` —— 只能是小写字母、数字和连字符，并且必须与所在目录同名。
- `description` —— 模型在判断这个技能是否适用时读的就是它。写给模型看，不是
  写给自己看。

每一轮开始时，Piem 会把已加载的每个技能列进系统提示，所以你不点名，模型也知
道它们存在。技能每轮都从磁盘重新读：改一个、加一个，**下一条消息**就生效，不
用重载插件。

在 **扩展能力** 中，技能名称旁的徽章标明 **导入**、**手写**、**单篇笔记** 或
**外部文件**；导入技能的来源 URL 保留在名称下方。读取问题列在对应分区下方，
标题旁显示问题数；技能标题旁的 **重新加载** 会重读文件、更新报告。文件夹搜索
报告会区分文件夹为空、不存在和无法检查。

### 从 GitHub 导入

**设置 → Piem → Extensions** 支持直接从 GitHub URL 导入技能：选一个仓库或子
目录，先看计划，然后 Piem 把那些 `SKILL.md` 写进 `Piem/skills/`，同时留一份
出处记录（provenance sidecar）。**Update** 按钮日后能重新抓取，靠的就是那份
记录。

导入只收 markdown。没有任何可执行的东西会顺着这条线下来。

## 提示模板

提示模板放在仓库里的 `.piem/prompts`，出现在同一套 `/` 自动补全里，并标注来
源。

如果一个模板和一个技能同名，模板优先，技能仍可通过 `/skill:名字` 访问。在自
动补全里选中它时，会自动插入那个消歧形式。

## MCP 服务器

Piem 通过 Streamable HTTP 连接远程 MCP（Model Context Protocol）服务器，把它
们的工具并入代理自己的工具表。在 **设置 → Piem → Extensions** 里配置：每个服
务器是一个 http(s) URL、一个可选的 Bearer 令牌，和一个启用开关。

- 工具对模型呈现为 `mcp_<服务器>_<工具>`，任何一份对话记录里都能分清远程工具
  和仓库工具。与已有工具重名时用数字后缀消歧。
- 服务器名称旁的徽章显示 **已连接** 及工具数、**连接中**、**连接失败**、
  **待连接** 或 **已停用**。开关决定是否启用，徽章说明实际连接结果；错误原文
  保留在名称下方。
- 保存设置会连接已启用的服务器，尚未打开聊天时也一样。URL 和令牌都没变的已
  连接服务器保持不动；改过的或失败过的会重新连接。待连接行旁有 **连接** 按钮，
  失败行旁有 **重试连接** 按钮，可立即再试。发送新消息也会刷新工具表；后台不
  会定时重试。
- 服务器编辑器里的 **测试** 按钮探测草稿配置，不必先保存。
- Bearer 令牌与服务商 API 密钥走同一套落盘密封生命周期。见
  [安全与隐私](security.zh-CN.md#你的密钥存在哪)。
- 超时是有界的：连接并列出工具 15 秒，单次工具调用 120 秒，工具输出按与其他
  工具相同的字节预算截断。

### 为什么只支持远程

不支持 stdio 传输。它要拉起子进程，而这在手机上是禁区——这个插件在手机上是一
等公民，不是事后想起来的补丁。一个在手机上不可能存在的能力，宁可对所有人都
不做，也不做成桌面端的意外惊喜。

也没有 OAuth 流程。一个静态 Bearer 令牌足以覆盖一个个人仓库现实中会对话的那
些服务器，而它替掉的那套流程需要一次浏览器往返——Obsidian 并不适合承载它。
