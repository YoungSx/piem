# 设置

[← 回到 README](../README.zh-CN.md) · [English](settings.md)

**设置 → Piem** 下有四页：Models、Chat、Extensions、General。

## 模型

这是唯一一页你必须去一次的。其余都有能用的默认值。

**服务商**是你自己的端点——Piem 不托管任何东西。一个服务商 = 一个 base URL、
一个 API 密钥、一种线路协议：

| 协议 | 适用于 |
| --- | --- |
| `openai-completions` | OpenAI 兼容的 `/chat/completions` 端点 |
| `openai-responses` | OpenAI 的 Responses API 及兼容端点 |
| `anthropic-messages` | Anthropic 的 Messages API 及兼容端点 |

**预设。** 从十六个已知服务里选一个，剩下只需填它的 API 密钥——表单会把名称、
base URL、协议三行收起来，因为预设已经把这三样定死了。可选：Anthropic、OpenAI、
Google Gemini、DeepSeek、Groq、Mistral、Moonshot、xAI、Z.ai、OpenRouter、
MiniMax、Qwen，以及其中四家单独运营的国内站。每个选项都标出它连的 host，因为那
才是区分一家厂商两个服务的东西。

**自定义**排在最前，也是新表单打开时所在的位置。它同时是你接管一个预设端点的方
式：切到「自定义」，那三行就回来，值还是预设填的，随你改。在自定义行里手打出某个
预设自己的 URL 会选中那个预设，改离开则退回「自定义」——标签绝不会描述一个表单
并没有拿着的端点。选预设不会动你的密钥。

模型 id 的建议来自端点自己——只要它支持列举。你自己的服务器比这个插件能内置的
任何东西都更清楚它会接受什么，也是唯一知道私有网关的那个。无论如何，这个字段
你手打任何 id 都收。

**能力建议。** 对已知的模型 id，表单会自动填上它是否接受图片输入、上下文窗口
多大、最大输出多少，数据来自 [models.dev](https://models.dev) 的实时索引，覆盖
它追踪的所有服务商。你手填的任何值都优先，并且从此不再被建议覆盖；索引拉不到时
每个控件都有能用的默认值。

**连接测试**走的是你为模型请求选择的那条传输通道——也就是你聊天时真正会用的那
条，而不是一条方便的替代。如果测试走 `fetch` 而聊天走 `requestUrl`，那测的就
是另一件事了。

**提示缓存**决定服务商可以把提示里不变的那部分——系统指令、工具定义、技能、你
当前打开的笔记——暂存多久，这样下一轮追问只按大约十分之一的价格读回来，而不是
重新付全价。

默认是**一小时**，这是有意偏离底层 agent 库自身默认值的。五分钟适合终端里的
agent，那里一轮接一轮只隔几秒；而你在两个问题之间写十分钟笔记，五分钟的缓存早
就过期了，整份提示会重新按全价计费。存一小时的存放费更高——Anthropic 对一小时
缓存写入收两倍基础输入价，五分钟是 1.25 倍——但第二次追问就把这笔溢价赚回来了。
如果你的会话真的只有一个问题，选**五分钟**；遇到会拒绝缓存标记的端点，选
**关闭**。

服务商会把这个偏好映射到自己支持的形式，不支持就忽略，所以这里的选择不依赖你选
了哪个模型。打开**显示 agent 细节**后，只要服务商报告了这个拆分，上下文圆环的弹
层就会写出其中按一小时费率写入的部分——这也是这个设置生效的唯一凭据，因为忽略它
的服务商只会安静地按便宜的那档收费。

## Chat

行为在上，存储在下。

有两件事在这里不经开关就会发生，都值得知道。你正打开的那篇笔记会被注入**每
一轮**——路径和正文都在——所以你永远不用说「我正在看的那篇」。以及上下文窗口
将满时，对话会自己整理；命令面板里的 *Tidy earlier thoughts*（中文界面为
「整理较早思维」）是同一件事的手动版，而每次整理都会在消息流里留下一道接缝，
点开就能读到它写下的总结。

- **Show agent details** —— 在聊天面板里显示 token 数、花费和原始工具参数。
  默认关；想看代理实际发了什么的时候打开它。
- **工具动态展开方式** —— 对话流里的机器流量（思考、工具调用、结果）默认展开
  多少。默认全部折叠，任何一行仍可手动打开。在这一档下，连续两条以上的思考和
  工具调用会一起收成一行，写明这一串干了什么——「读取了 1 条笔记并思考了 1 次」
  ——原来的各行仍按顺序留在里面。失败的调用和已回答的提问不进折叠：这两样
  都不该让人点一下才看见。
- **回复途中发送** —— Piem 还在回答时你发出的消息不会被拒绝，它会排队等着，
  这一项决定等多久。默认也更稳的一档是「整段回答结束」：这条回复把自己的计划
  做完，你的消息才作为下一个问题被读到。「当前这次请求结束」更快——消息落在这
  一轮的工具跑完、Piem 再开口之前，因此可以在一长串工具调用中途改掉它的方向。
  两档都不打断：真正打断的是等待条上的**发送**按钮，它会掐断当前回复，让那一
  条立刻出去。
- **上下文整理** —— 决定什么时候把对话总结掉腾地方的 reserve 与
  retention 预算。Piem 按你为该模型配置的上下文窗口来规划。
- **Chats to keep** —— 会话保留上限。超过上限后你再新建会话，最旧的那些会被
  移到废纸篓。设成不限，就永远不会有东西被丢掉。
- 会话目录就显示在这一页，所以你随时知道自己的对话记录躺在哪个文件夹。

## Extensions

MCP 服务器、技能导入和内置技能文件。**内置技能文件** 显示准备状态，以及因
本地修改而保留的文件。**重试准备** 重试下载；**恢复缺失文件** 恢复已删除的
内置入口，不覆盖修改。**重新加载** 只重读本地技能。目录、优先级和更新规则见
[扩展 Piem](extending.zh-CN.md)。

## General

- **语言** —— 英文或简体中文。默认跟随 Obsidian 自己的语言；这里的覆盖是为了
  「我想让插件跟应用不同语言」这种情况。
- **发送快捷键** —— <kbd>Enter</kbd> 发送，或者
  <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Enter</kbd> 发送、<kbd>Enter</kbd> 换行。
  挑你已经有肌肉记忆的那个。
- **日志等级**与**日志查看器** —— 日志视图作为独立叶子打开，服务商行为异常时
  第一个该看的就是它。
- **About** —— 正在跑的版本（从 `manifest.json` 读，绝不另抄一份）、若干链
  接、什么会离开你的仓库的摘要，以及你的密钥在这台设备上是怎么存的。

## 命令

Piem 加进命令面板的全部内容，显示为 *Piem: …*：

| 命令 | 做什么 |
| --- | --- |
| Open chat | 打开聊天侧栏 |
| Open log view | 打开日志叶子 |
| New chat | 起一段新对话 |
| Stop response | 中止正在进行的这一轮 |
| Tidy earlier thoughts | 手动压缩对话 |
| Focus chat input | 把光标跳进输入框 |
| Ask about selection | 将选中文字和笔记路径加入草稿 |
| Ask about this note | 将当前笔记路径加入草稿 |

它们都能在 **设置 → 快捷键** 里绑定成你自己的热键。

### 从右键菜单提问

在 Obsidian 文件菜单中选择 **询问此文件**、**询问此文件夹** 或 **询问所选项目**。
编辑器中，选中文字时提供 **询问所选内容**，没有选区时提供 **询问此笔记**。
外部 HTTP/HTTPS 链接提供 **询问此链接**。

每次操作会在文字输入框内、问题上方加入可展开的引用卡片；卡片和文字共用一个
焦点框。展开后可以查看完整路径、网址或当时
选中的文字；移除卡片，就不将它附在下一条问题里。你自己写的问题保持原样，准备
好后再选择 **发送**。打开菜单或加入卡片不会抓取网页，也不会启动模型请求。

卡片属于当前草稿，关闭面板或切换对话后仍会保留。新对话加入第一张技能或引用卡片时会保存
会话身份，重启 Obsidian 后也能找回未发送的草稿；只打开空白对话不会保存。
问题排队时卡片一起排队，取回编辑时一起回来；发送后，卡片和技能包装一样，放在
所属问题的消息气泡里，重新打开对话仍保持这层归属。选择技能，或在已知的
`/skill:名称` 后输入空格，会在文字输入框里显示同款可展开卡片，文字区只保留问题。
移除技能卡片会移除技能调用，保留问题和其他引用。卡片和实际发送的技能都从同一份
草稿推导，恢复草稿后仍一致。引用使用 Pi 原生自定义消息
保存：模型读取引用文字，界面读取单独的卡片资料。文件和目录卡片只标明路径，
不代表已经读取全文；选区卡片保留选择当时的文字。

一份草稿最多附带 64 个引用，引用资料合计不超过 20,000 字符。问题文字沿用原本的
保存上限：前 20,000 字符会保存，当前编辑器仍保留全文。重复引用会合并，超额追加
会说明原因并拒绝，不可用项目也会提示。
较长选区会截到 2,000 个 Unicode 字符并提示。独立的 **固定** 控件仍支持八个长期
文件引用；给单条问题加卡片不占固定名额。

保存的草稿加载期间，输入框暂时只读。手机上加入引用会展开输入框，并将光标放到
问题里。发送后，`web_fetch` 可请求网页，受网站访问权限及工具文本上限约束。
当前笔记有打开的编辑器时读取最新文字，包括未保存修改；已关闭笔记读取保存版本。
菜单由 Obsidian 提供，不同自定义视图或手机手势可能显示不同入口。

## 存储

会话是 JSONL 文件，放在
`<仓库配置目录>/plugins/piem/sessions/`，用 pi 兼容的第 3 版头部和树形条目
（`id` / `parentId`）写入——和 pi 用的是同一种形状，所以一份对话记录不会被这个
插件扣住。

未发送的文字和引用卡片存在日志旁边各自的 `drafts/<session-id>.json` 中，关闭面板
后两者都会保留；旧的纯文字草稿仍可读取。

暂存的图片**从不**落盘。会话日志里存的是一个占位符而不是字节，所以一个会同步
的仓库不会把你的截图带着到处跑。

## 版本

正在跑的版本住在 `manifest.json` 里，并显示在 **About** 中。已发布的各版本、
以及每个版本所需的最低 Obsidian 版本，记录在
[`versions.json`](../versions.json)。
